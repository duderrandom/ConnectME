# ConnectME

## 📌 Overview

**ConnectME** is a web platform designed to connect developers, designers, and tech enthusiasts from around the world to seamlessly form hackathon teams. Whether you're searching for teammates with complementary skills to round out your stack or exploring upcoming coding events, ConnectME transforms the chaotic team-building process into a streamlined, effective experience.

---

## ✨ Features

### 👤 User & Team Features
- Secure user registration and authentication  
- Comprehensive developer profile creation and skill management  
- Intuitive team formation with integrated matchmaking  

### 🎯 Hackathon Discovery
- Explore and track upcoming hackathon listings globally  
- Advanced filters and search options by tech stack and event type  
- Personalized teammate and project recommendations  

### 💅 UI/UX Enhancements
- Global back-to-top button across all directory pages  
- Integrated chatbot assistant for quick platform navigation  
- Clean, modern icon upgrades utilizing Lucide React  
- Redesigned headers and dashboard layouts for visual consistency
